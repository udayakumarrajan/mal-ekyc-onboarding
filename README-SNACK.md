## 🚀 Quick Start

### Option 1: Import to Snack
1. Go to https://snack.expo.dev/
2. Click "Import" → "Import from GitHub"
3. Use URL: `https://github.com/udayakumarrajan/mal-ekyc-onboarding/tree/snack-demo`

`https://snack.expo.dev/@github/udayakumarrajan/mal-ekyc-onboarding@snack-demo`
