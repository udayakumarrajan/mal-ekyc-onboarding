# eKYC Onboarding - Mobile App Demo

A complete eKYC (electronic Know Your Customer) onboarding mobile app built with Expo React Native.

## 🚀 Features

- ✅ JWT Authentication
- ✅ 5-step onboarding flow (Profile → Document → Address → Consents → Review)
- ✅ Theme toggle (light/dark mode)
- ✅ Async verification with polling
- ✅ Draft persistence
- ✅ Token refresh
- ✅ Full TypeScript
